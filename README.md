# Merge Arrays TypeScript Project

This project implements a function to merge three arrays into a single **ascending sorted array** without using the built-in `sort()` function.  
It also includes **unit tests** using Jest.

## 📂 Project Structure
src/
│ └─ merge.ts # Function implementation
├─ tests/
│ └─ merge.test.ts # Unit tests
├─ package.json # Project dependencies and scripts
├─ tsconfig.json # TypeScript configuration
└─ jest.config.js # Jest configuration

## ⚙️ Setup

 **Clone the repository**

```bash
git clone <repo-url>
cd merge-ts-project
npm run build
npm run test // Runs Jest tests from tests/ folder.
